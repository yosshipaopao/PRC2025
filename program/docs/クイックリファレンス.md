# クイックリファレンス（仕様書要約）

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| **プロジェクト名** | PRC2025 Main Program |
| **対象ハードウェア** | ESP32S2 (Arduino) |
| **主要機能** | ライントレーサーロボット制御 |
| **開発言語** | C++ |
| **フレームワーク** | PlatformIO (Arduino Framework) |

---

## 2. ハードウェア構成

### 2.1 マイコン
```
ESP32S2 Development Board
└─ UART1: MP3プレーヤー (DFRobotDFPlayerMini)
```

### 2.2 モーター制御
```
モーター M1~M4（DC 4個）
├─ M1, M2: グループ1（左側） → run_motor(left_speed, ...)
└─ M3, M4: グループ2（右側） → run_motor(..., right_speed)

各モーター:
  Left Pin:   方向制御（前進）
  Right Pin:  方向制御（後進）
  PWM Pin:    速度制御 (0~255)
```

### 2.3 センサー
```
赤外線ラインセンサー × 6個
├─ ピン: [13, 14, 15, 16, 17, 12]
├─ 閾値: 2000
└─ 出力: 6ビット状態値 (0b000000 ~ 0b111111)
```

---

## 3. クラス一覧

| クラス | 説明 | 主メソッド |
|--------|------|-----------|
| **Motor** | DC モーター制御 | `run(speed)`, `stop()` |
| **Sensor** | ラインセンサー読込 | `read()`, `state()`, `get(pin)` |
| **MotorPowerAverager** | 速度スムージング | `addPower(l,r)`, `getL()`, `getR()` |
| **StateManager** | 状態管理・遷移検出 | `updateState()`, `mapState()`, `getCurrentState()` |
| **TimeoutManager** | イベント再発防止 | `set(id, ms)`, `get(id)` |
| **Debug** | デバッグ出力 | `println()`, `print()` |

## 5. 状態グループ（StateManager）

| Group ID | 説明 | センサー状態例 |
|----------|------|----------------|
| **0** | 中央（直進） | 0b00100, 0b01110 |
| **1** | 左寄り | 0b110000, 0b111000 |
| **2** | 右寄り | 0b00111, 0b01111 |
| **3** | ラインなし | 0b00000 |
| **4** | 全センサー（十字） | 0b11111, 0b111111 |
| **-1** | 未登録（前状態維持） | - |

## 6. イベント検出

### 6.1 C字折り返し検出

```
条件:
  ✓ prev_state = 1 (左寄り)
  ✓ current_state = 0 or -1 (中央またはなし)
  ✓ prev_state_count >= 10 フレーム
  ✓ timeout_manager.get(0) == false

動作:
  left_speed = 0 (停止)
  right_speed = 130 (全速)
  delay(2000ms)
  timeout = 5000ms
```

### 6.2 十字交差点検出

```
条件:
  ✓ prev_state = 4 (全センサー)
  ✓ current_state = 0 or -1 (中央またはなし)
  ✓ prev_state_count >= 10 フレーム
  ✓ timeout_manager.get(3) == false

動作:
  cross_count++
  timeout = 3000ms
  ※ モーター制御は継続（特に変更なし）
```

### 6.3 C字復帰検出

```
条件:
  ✓ current_state = 3 (ラインなし)
  ✓ current_state_count >= 100 フレーム
  ✓ timeout_manager.get(1) == false
  ✓ timeout_manager.get(0) == false

動作:
  left_speed = -130 (後進)
  right_speed = 130 (前進)
  delay(2000ms)
  timeout = 5000ms
```

## 7. ラインセンサー状態別のモーター制御

| センサー | 左速度 | 右速度 | 説明 |
|---------|--------|--------|------|
| 0b11111 / 0b01110 / 0b00100 | 130 | 130 | 直進 |
| 0b01010 / 0b01101 / 0b10110 | 130 | 130 | 直進 |
| 0b11110 / 0b01100 / 0b11100 | 70 | 130 | 左舵切 |
| 0b00110 / 0b00111 | 130 | 70 | 右舵切 |
| 0b01000 / 0b11000 | 0 | 130 | 強左舵 |
| 0b00010 / 0b00011 | 130 | 0 | 強右舵 |

| 0b00001 | 130 | -130 | 右旋回 |
| 0b00000 | - | - | 無操作 |

## 8. メインループ フロー

```
loop() {
  1. yield()                          // ウォッチドッグリセット
  2. nextLoopTime の同期調整
  3. sensor.read()                    // センサー読込
  4. state_manager.updateState()      // 状態更新
  5. イベント検出処理
     ├─ C字折り返し検出
     ├─ 十字交差点検出
     └─ C字復帰検出
  6. switch-case でモーター速度指定  // ライントレーサー
  7. _run_motor()                     // モーター実行
}
```

## 17. トラブルシューティング表

| 症状 | 原因 | 対処法 |
|------|------|--------|
| ロボットが動かない | センサー値がすべて同じ | 閾値を調整 |
| 黒線を追従しない | 速度が速すぎる | RUN_SP を低減 |
| 曲がり過ぎる | 舵切り強度が強い | HALF_STOP_SP を増加 |
| C字が検出されない | センサー感度不足 | threshold を減少 |
| 頻繁に誤検出 | ノイズが多い | C_detection_threshold を増加 |
| イベント重複実行 | タイムアウト不足 | set() の時間延長 |

## 18. 状態遷移のポイント

```
重要: 状態は "5フレーム以上" の継続で初めて "確定" される

例:
  フレーム0-4:    状態 A → B に変化 (count=0,1,2,3,4)
  フレーム5:      状態 B で count=5 に達して初めて "確定"
  フレーム6:      イベント検出可能（前フレーム状態 = A）
```

## 19. 電源管理

```
推奨電圧: 3.3V (マイコン)
モーター電圧: 別途 6-12V 電源推奨

電池交換時期: 
  モータが力弱くなったら → 電圧低下の可能性
  
対策:
  RUN_SP を減らしてテスト
  または電池を交換
```
